# IML 0.5 measurement, 2026-09-18

Corpora: the 20 documents of `corpus/golden-0.5/`, the 72 golden chains of `corpus/golden/` (unchanged since 0.2) and the 36 golden chains of `corpus/golden-0.4/`. Registry `registry/iml-registry-0.5.json`, digest `7e29fae7f5ea` (the 0.5 header); chain registry `registry/iml-registry-0.2.json`, digest `88d05d0839c1` (the 0.4 and 0.2 records); canon commit `127ba56f4eb1`.
Python 3.13.15. tiktoken 0.14.0.

Units: bytes (UTF-8), characters (code points), tokens under the named tiktoken encodings `cl100k_base`, `o200k_base`. Tokenizer scope: the named encodings, not any vendor's billing.

Forms, per document of `corpus/golden-0.5/`: **I-Lang as written** is the `.ilang` file as it stands on disk, final newline included (blank lines, `---` lines, indentation and trailing whitespace are layout and counted here); **I-Lang canonical** is `print_doc` of the parsed document with one final newline; **IML 0.5 document** is the `.iml` file as it stands on disk, final newline included, which equals `compile_doc` of the parsed document plus one newline (checked when this report ran).

Forms, per chain: **I-Lang** is the canonical print (`print_L2`); **IML 0.5 message** is the compiled message including its header `#iml/0.5/7e29fae7f5ea ` (one header per chain); **IML chain line** is the chain as it stands on one line of a document; **JSON** is the one JSON mapping used as baseline, stated here: `{"c":[{"v":VERB,"t":"@TARGET","r":VERBREF,"m":{key:value}}]}` compact with no spaces, `t`, `r` and `m` omitted when absent, entity references as `"@NAME"`, every other value as its content string. Per chain corpus: **IML 0.5 document** is the header alone on the first line and then the chains, one per line, measured as one text. The records: **IML 0.4 message** and **IML 0.4 document**, the same texts under the 0.4 header `#iml/0.4/88d05d0839c1 ` (for `corpus/golden-0.4/` the message is the `.iml` file on disk, which is that text), and **IML 0.2 message** (the 72 chains only), the 0.2 surface, header `#iml/0.2/88d05d0839c1 `.

No figure below carries a claim of any kind; the table is the table (ROADMAP gate: efficiency claim).

Reply cost: not measured in 0.5, the codec makes no model calls (ROADMAP item 13 lists the reply; it is counted when a model reads IML, not here).
